# 多楼层拓扑与沿路线执行开发清单

目标：场景作者绘制带高度的节点与连边，标注楼层、楼梯入口/出口和房间；
模型输出明确目标标识后，通用路由层生成有序 XYZ 节点路线，沿用 EAI 底盘速度
skill 和机器人已有运动控制器。场景任务和原生诊断放 tmp，不创建正式实验合同。
