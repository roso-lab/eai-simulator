# 任意角度 PickPlace：当前实现与验收

更新日期：2026-10-20。本文件描述 `codex/cartesian-pick-place` 当前实现，
原交接文档中的设计建议不能直接视为已实现或已验证功能。

## 请求与执行

默认保留 `vertical_legacy`。UR5/Z1 可显式使用 `cartesian_pose`，提交
`grasp_pose_object`、`approach_direction_world`、`pregrasp_distance_m`、
`retreat_distance_m`、`approach_speed_m_s`。调用示例和字段见 [README](README.zh-CN.md)。

`target_pose` 始终是物体原点的世界坐标。抓取帧是物体局部帧；工具局部 +Z
在接触点背离物体，必须与接近方向相反。预抓取与撤离点沿接近方向反向偏移。
抓取帧表示两指间的 TCP，不能直接作为腕部坐标。UR5 的 TCP 在腕部 +Z 方向
150 mm，TCP 相对腕部绕 X 旋转 180°；Z1 夹指沿 link06 的 +X，TCP 位于该轴 195 mm（距指尖 5 mm），相对腕部
绕 Y 旋转 -90°，并按单侧固定夹指和物体宽度修正中心。
适配器先将 TCP 位姿转换为腕部 IK 目标。place 根据实测腕部到物体变换和
对应夹爪的外向轴反求接触位姿，不把物体原点当作放置腕部位置。
`orientation_xyzw` 指定最终物体姿态的功能仍不支持，不能与接近姿态混淆。

运行阶段为：

```text
pick : PREGRASP → APPROACH → GRASP → LIFT → ATTACHED_HOLD
place: PREGRASP → APPROACH → RELEASE → LIFT → IDLE
```

宿主每个物理 tick 调用 `run_post_apply`，推进位置和四元数插值、全姿态 IK、
夹爪目标、实测到位门控和 follow proxy。公共操作仍只返回布尔值。
姿态、位置、关节稳定、夹爪到位与停留时间均参与门控；规划成功不等于操作成功。

## UR5 夹爪动画

UR5 使用 Robotiq 2F-85，并参考 Z1 的 PickPlace 阶段适配：

| 阶段 | UR5 `finger_joint` | Z1 `jointGripper` |
| --- | --- | --- |
| 接近、空手结束 | 0 rad（张开） | 按物体尺寸保留开口余量 |
| 抓取、抬升、持物、放置接近 | 按投影宽度闭合；50 mm 约 0.376 rad | 按固定指与旋转指几何闭合 |
| 释放 | 渐变到 0 rad | 渐变到本次计算的张开角 |

目标以 0.8 rad/s、按物理步渐变；时长由本次角度差决定。动画通过真实关节 drive
产生，不直接写手指位姿。阶段切换重新读取实测角度，挂接与释放等待实测角度
达到最终目标；中间动画目标不能触发成功。UR5/Z1 pick 同时检查腕部和
实测 TCP 的 5 mm 位置门限。物体尺寸来自 live USD 投影边界，超出标定开口明确拒绝。

## 本轮修复

- 固定基座 PhysX Jacobian 不含根链接行，`link_paths` 含根链接；按实际行数
  解析末端行，修复安装 Robotiq 后腕部 Jacobian 错位。
- 在关节限位处求解带上下界的 DLS，让剩余可动关节继续消除误差。
  原无约束解直接截断会使 Z1 在 `-30°` place 姿态停滞；未放宽到位容差。
- 验收宿主使用弯曲的 UR5 初姿态，同时写关节状态和驱动目标，避免首段向零目标塌落。
  每物理 tick 运行控制；实例代理在初始化前解除实例化，保留全部机械臂碰撞体。
  桌面边沿避开基座和肩部，逐物理步检测机械臂视觉/碰撞网格包围盒与桌面是否分离。
- Z1 使用靠近指尖的抓取中心，避免旧 180 mm 插入深度使倾斜指腹擦碰支撑面；闭合角按新的物体近侧角点重算。
- place 释放时恢复物体与桌面的接触，仅临时过滤本次物体与机械臂的碰撞对，
  避免张开中的夹爪将物体弹走。撤离完成、空手取消或 reset 都恢复原过滤关系。
- 记录实测开合轨迹、单次挂接/释放、持物抬升、最终放置误差、物体属性恢复、
  资源清理与运行前源码哈希，运行中源码变化会使报告拒绝通过。

## 边界

当前采用用户指定的理想化抓取模型：pick 隔离源物体碰撞，持物使用 follow proxy。
机械臂与环境碰撞保持开启；每例检查初始保持、全轨迹桌面间距和释放后的过滤恢复。
已测桌面场景的轨迹分离证据不提供通用障碍规划、接触力闭合或负载能力的保证。
任意角度仍受工作空间、关节和夹爪能力限制，未覆盖的姿态不能由已通过角度外推。
可选 `reachable_cartesian` 回调支持宿主预检；没有通用全工作空间可达性保证。

同一物体仍只有一个占用者；两只机械臂同步共抓同一物体的 composite adapter、
联合 IK 与接触约束不在当前实现中。独立实例的资源管理不能替代双臂共抓协调。
