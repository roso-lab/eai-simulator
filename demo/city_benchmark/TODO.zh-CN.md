背景车辆接近事故车的自动暂停属于场景行为，不能给模型记分。

## S2 地图与配置

- [x] 在内存中按真实 defaultPrim 引用关系组合 USD，扫描建筑、树/灯和公交站。
- [x] 导出 0.25 m/cell 地面 PNG/YAML、语义区域、3D 包围盒和静态路线。
- [x] 未声明地面保持 unknown；障碍和台阶边界保守膨胀；集合点不宣称安全/容量。
- [x] 绑定源 JSON/USD 以及所有组合层哈希，并在输出前检查源未变化。
- [x] 审计 demo 机器人起点，产生相距至少 3 m 的附近候选点；不自动部署。
- [x] 生成选队配置 helper，支持审核后的起点覆盖，拒绝重复/隐藏成员和预算超额。

反思：原文件 `/World/City` 下只有生成街道，建筑是 `/World` 的直接子级；错误根路径会生成
缺少建筑的危险地图。行人路线中心通常贴路沿，直接选中点无法容纳集合净空。
检验：真实资产导出获得 23 栋建筑、246 组静态障碍、12 条车路线、6 条步行路线、
12 处过街点和 4 个静态候选集合点；预览人工检查方向与路线。
后续条件：这些是保守几何配置，尚不证明车辆/人/机器人动态避碰、support/contact 或烟火净空。

## S3 任务与审核契约

- [x] 只发布业务结果，复用共享 public task 和 participant API validator。
- [x] 保留可选机器人池，不给 DAG、资格答案、受影响任务答案或未来时序。
- [x] 记录 guide_people / control_traffic / report_incident 的扩展需求、证据和失败语义。
- [x] 增加人员响应状态机：观察、逐人引导确认、跑步动作、集合到达和无响应状态。
- [x] 增加 USD 人类运行时适配：已确认后切换 `jog` 与更高路径速度，到达后恢复 `walk`。
- [x] 将交通控制限定为事故后的跟随车辆，并强制区分请求、确认和控制证据。
- [x] 固化业务证据判定骨架：观察新鲜度、当前 ETA 派遣、逐人集合、交通反应窗口和报告回执。
- [x] 将人员/车辆隐藏全集绑定和通信、成员变化的因果影响写入作者侧任务逻辑。
- [x] 作者反例检查：缺通路证据、时间倒序、重复实体、缺隐藏全集均拒绝；合法非最小 ETA 分配接受。
- [x] 草稿时限和计时锚点由同一 policy 生成到公开 business_constraints 与 private.task_logic。
- [x] 明确事故脚本和独立响应时间预算，防止视觉 loop 重置破坏实验。
- [x] 缺完整业务见证时返回 authoring_status=blocked / scoreable=false。
- [x] 明确观察后动态人员/车辆身份尚不能被共享计划验证器完整引用。

反思：换一个 ground agent 的导航计划不能冒充完整城市响应见证；导航到人附近不等于疏散，
提交控制请求也不等于后续车辆已经停车或改道。
人员和后续车辆必须先通过 participant 可见观察引用进入服务请求；“已确认”之后仍须等待真实
轨迹或人员集合证据。人员/车辆全集属于 evaluator 隐藏真值，不能只凭参与者提交的部分名单
推断任务完成。最小 ETA 不是唯一合法分配；通路净空与报告回执是两个独立的业务必要证据。
局部正例不能替代隐藏全集绑定，也不能替代真实运行时验证。
检验：公开契约能够校验，作者审查仍阻止正式发布；没有伪造 hidden_evaluator 或 full mission witness。
