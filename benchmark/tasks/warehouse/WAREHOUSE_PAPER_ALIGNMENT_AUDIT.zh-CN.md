# warehouse 论文对齐审计

warehouse 的六节任务设计、`warehouse_task_manifest.v1.json` 和 difficulty contracts 共同冻结订单、语义绑定域、搜索、重货联合搬运、workspace 充电和 checkpoint 证据。T1–T4 分别对应已知拣选、区域搜索、多订单重货协作和多楼层高峰服务；条件不改变任务语义。

P1/P2/P3-J/P3-S/P4 仅在逻辑事件账本中诊断。ground/aerial 资格由 semantic-points navigation bindings 求交，不把 low/high 标签当作能力证明。floor2/floor3 仍需 runtime 一致性和 route witness。`robot_validated=false`、`physical_qualified=false`、`runtime_oracle_bound=false`、`paper_score_eligible=false`。
