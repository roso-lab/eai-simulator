# 下一阶段功能规划

> **规划状态**：本页描述的能力目前处于规划与开发阶段，尚未包含在当前发布版本中。最终功能范围与发布时间以正式版本为准。

下一阶段，EAI Simulator 将进一步增强动态人机共融环境中的仿真与协作能力。规划内容围绕虚拟人、团队协作、城市环境和多机器人导航四个方向展开，帮助研究者构建更真实、更复杂的人机混合实验。

## 更丰富、更自然的人类资产

项目计划扩充虚拟人类资产，提供更多外观与身份特征，并加入招手、聚集等社会化行为。同时，系统将为对话能力预留扩展接口，为研究人与机器人之间的交流、协作和群体行为提供基础。

## 面向动态人机协作的团队规划

在现有的多机器人讨论与任务分配方案（EMOS）之外，项目计划引入面向动态人机协作的新方案 [TeamWeaver](https://github.com/southking372/TeamWeaver#teamweaver-hybrid-llm-and-optimization-based-planning-with-transparent-constraints-in-heterogeneous-multi-robot-teams)。

TeamWeaver 将使用语言模型理解任务语义并形成规划约束，再通过数学优化完成具体的任务分配与调整。当人类临时加入任务、改变环境状态，或与机器人发生空间冲突时，该方案计划根据最新状态重新协调机器人分工和行动，重点改善动态场景中的响应效率、决策透明度与可追溯性。

## 可交互的社会化城市场景

项目计划新增一个完整的城市仿真环境，包括城市街景、道路、行人和车辆。场景将加入基础车流组织与管制、车辆礼让行人等社会化交通行为，用于开展城市道路、多类交通参与者，以及人、车辆与机器人共存环境下的研究。

## 面向多机器人的协同导航

项目计划升级现有导航能力，引入面向多机器人场景的 db-CBS 协同导航方案，并逐步替换当前的通用二维全局规划器。

新方案将统一考虑多台机器人的位置、目标和路径冲突，为机器人规划相互协调的通行路线，用于减少会车冲突、相互阻塞和局部拥堵，更好地支持多台机器人同时运行的复杂任务。
