Env DIY 教程

本网页按 Scenes、Robots、Payloads、Tools、配置和审查六个步骤复现轻量 2D 流程；Payloads 下分为 Manipulators 和 Sensors。它不是 Isaac Sim Viewport，真实 spawn_pose 请运行 python simulator.py --diy-3d。Isaac Sim 扩展会默认停靠在右侧，目录使用本地缩略图，并在 Placed Robots 中显示每个 robot ID 的生成状态；拖放机器人时会校验 PhysX 碰撞表面，Run 会通过状态栏和 Kit 通知报告未解决的失败，UR5/Z1 作为固定 Payload 装配到宿主。

状态提示：--diy-3d 仍处于持续优化阶段，插件布局、资产目录和部分控制器接口可能随版本调整。开发或联调时请保留导出的 selection JSON，并在正式实验前锁定仓库版本。

Isaac Sim 3D 编辑模式

真实的高度、碰撞和 spawn_pose 需要在 Isaac Sim Viewport 中编辑。本页的 Browser 2D 画布只用于熟悉配置结构与导出 JSON。当前 --diy-3d 仍处于持续优化阶段，插件布局、资产目录和控制器接口可能随版本调整。

  1. 在工程根目录运行 python simulator.py --diy-3d --device=cuda:0。
  2. Isaac Sim 启动一次后，右侧打开 Env DIY 3D 插件，依次选择 Scenes、Robots、Payloads 和 Tools。
  3. UR5/Z1 会固定装配到兼容宿主；每个机器人保持独立 assembly，新增或失败不会清除其他有效机器人。
  4. 在 Run 前检查 USD 与 controller cfg。缺失资产可单项下载，或用 Download all and run 一次性准备。
  5. 点击 Run 后销毁预览 Stage/资源，并在同一个 Kit 进程中创建正式环境，随后进入仿真循环。
