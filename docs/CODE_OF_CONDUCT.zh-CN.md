# 行为准则

EAI Simulator 希望维护一个尊重、技术导向、开放协作的社区。

## 期望行为

- 欢迎不同背景、经验水平和研究方向的参与者。
- 针对想法、代码、实验和文档给出具体的技术反馈。
- 默认善意，必要时先澄清，并让讨论聚焦在项目本身。
- 通过可复现信息和清晰范围尊重维护者时间。
- 对敏感报告遵循项目安全策略。

## 不可接受行为

- 骚扰、辱骂、威胁、人身攻击或持续干扰。
- 歧视性语言或行为。
- 公开私人信息、凭据、安全细节或内部项目材料。
- 垃圾信息、无关推广，或在维护者提醒后反复发布低质量内容。

## 执行

当行为损害社区或项目时，维护者可以编辑或删除评论、锁定讨论、关闭 issue、拒绝贡献或限制参与。

如果需要私下报告行为问题，请通过私有渠道联系维护者，不要创建公开 issue。
