# 安全策略

## 支持版本

项目仅对默认分支的最新版本提供主动安全更新。

## 报告安全漏洞

不要在公开 Issue、Pull Request、Discussion 或聊天中披露疑似漏洞。

1. 使用 GitHub 私有漏洞报告：
   <https://github.com/roso-lab/eai-simulator/security/advisories/new>。
2. 如果你是内部维护者，也可以创建 GitLab confidential issue。
3. 提交技术细节前，请确认报告渠道是私有的。
4. 如果没有可用的私有报告渠道，不要通过公开渠道提交漏洞细节。请先联系维护者索取私有渠道。

报告中请包含受影响的版本或分支、漏洞类型、潜在影响、复现步骤、相关日志、可用时提供
最小 PoC，以及建议的缓解措施。

## 协调披露

在维护者确认适合披露之前，请对报告和相关技术细节保密。维护者将通过 Confidential Issue
协调验证、修复和披露。本项目不承诺固定的响应或修复时限。

## 非安全问题

普通 Bug、文档问题和功能建议请使用公开 GitHub Issues。
