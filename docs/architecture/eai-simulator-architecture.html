System overview

配置驱动的仿真开发框架

从实验描述到环境装配、仿真运行和外部系统连接，各阶段围绕统一的 Isaac Sim 运行时协同。

每一行表示一个工作流阶段，以及负责支撑该阶段的架构层。

01

资源与配置层

Declarative inputs

描述进入仿真的资源、实体能力、空间关系与任务约束，保持实验输入可保存、可复用。

环境构建层

Dynamic assembly

把声明式选择转换为可执行的场景与环境配置，并在启动前完成兼容性和依赖检查。

统一承载物理步进、渲染、状态更新、感知输出以及面向实体的控制循环。
