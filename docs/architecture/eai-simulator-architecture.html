System Overview

配置驱动的仿真开发框架

从实验描述到环境装配、仿真运行和外部系统连接，各阶段围绕统一的 Isaac Sim 运行时协同。

每一行表示一个工作流阶段，以及负责支撑该阶段的架构层。

  1. 01
    描述实验 Describe experiment
    资源与配置层 Declarative inputs
    查看文档

    描述进入仿真的资源、实体能力、空间关系与任务约束，保持实验输入可保存、可复用。

  2. 02
    装配环境 Assemble environment
    环境构建层 Dynamic assembly
    查看文档

    把声明式选择转换为可执行的场景与环境配置，并在启动前完成兼容性和依赖检查。

  3. 03
    运行仿真 Run simulation
    Isaac Sim 运行时 Shared simulation runtime
    查看文档

    统一承载物理步进、渲染、状态更新、感知输出以及面向实体的控制循环。

  4. 04
    连接实验 Connect experiment
    接口与实验层 External integration
    查看文档

    读取仿真反馈、接收外部目标，并将算法、工具和实验编排接入同一个运行过程。

开发过程形成可重复执行的闭环，每一步都可以独立替换或复用。

  1. 01
    准备资源 Prepare resources
    依赖解析 Prepare
    查看文档

    根据实验声明识别所需资源，检查本地状态并补齐运行依赖。

  2. 02
    生成配置 Generate configuration
    声明式装配 Configure
    查看文档

    将实验选择编译为场景、实体和运行参数，使同一描述能够稳定复现。

  3. 03
    执行循环 Execute loop
    仿真会话 Simulate
    查看文档

    管理应用与环境生命周期，在共享场景中持续推进世界状态。

  4. 04
    观察迭代 Observe & iterate
    反馈与评估 Evaluate
    查看示例

    把运行状态提供给外部实验，依据结果调整配置并进入下一轮。

架构通过清晰边界隔离资源获取、配置生成、仿真状态和外部应用。

  1. 01
    资源供给 Asset supply
    资产边界 Asset boundary
    查看文档

    源码只声明资源需求，体积较大的运行资产独立管理并按需进入本地缓存。

  2. 02
    配置编译 Compile configuration
    构建边界 Builder boundary
    查看文档

    稳定的数据结构与具体运行配置分离，编辑工具和终端流程共享同一份语义。

  3. 03
    状态演化 State evolution
    运行时边界 Runtime boundary
    查看文档

    环境负责状态与动作协议，任务逻辑不侵入底层物理和场景生命周期。

  4. 04
    系统接入 System integration
    应用边界 Application boundary
    查看算法

    算法与实验通过会话和接口契约接入，保持可独立开发、替换与验证。

架构原则

设计理念

声明式 实验描述与运行实现分离，让环境能够保存、检查和重建。
可组合 资源、能力、接口和实验逻辑可以按工作流需求重新组合。
运行时解耦 共享仿真状态保持稳定，外部算法和实验围绕标准契约演进。
配置驱动 JSON 描述是唯一入口，同一个环境描述在编辑工具和批量运行中行为一致。
